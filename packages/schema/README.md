# @tablewright/schema

The typed boundary between the TypeScript apps and the Rust core.
`src/bindings.ts` is generated by tauri-specta from the commands in
`apps/table/src-tauri/src/commands.rs`. Never edit it by hand: Rust is
the source of truth for every type in it.

- `bun run schema` regenerates it, and dev builds of Table regenerate
  it on start.
- A Rust test fails `bun run check` when the committed file is stale.

The generated `commands` object calls Tauri's `invoke`, and that import
is the one transport seam: the browser player client will alias
`@tauri-apps/api/core` to an `invoke` over a WebSocket at build time.
So components import this package, never Tauri directly (design §6).
