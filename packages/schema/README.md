# @tablewright/schema

The typed boundary between the TypeScript apps and the Rust core.
`src/bindings.ts` is generated by tauri-specta from the command surface
in `apps/table/src-tauri/src/commands.rs`; never edit it by hand.

- `bun run schema` regenerates it. Dev builds of Table also regenerate
  it on start.
- A Rust test fails `bun run check` when the committed file is stale.
- Rust is the source of truth for every type in it (house rule).

The generated `commands` object calls Tauri's `invoke`. That import is
the one transport seam: the browser player client will alias
`@tauri-apps/api/core` to a WebSocket-backed `invoke` at build time, so
components import this package and never Tauri directly (design §6).
