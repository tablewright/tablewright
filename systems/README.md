# Systems

One directory per game system that ships with Tablewright. Design:
[docs/design.md §3](../docs/design.md), "Systems and modules".

```
systems/<system>/
  system.json                  # the system: id, versions, mechanics choices
  content/<version>/<module>/  # bundled compendium modules
    module.json                # id, name, version, licence, attribution
    <kind>/<slug>.json         # one entry each, in the envelope shape
  src/                         # a Rust crate, only for coded systems
```

A module directory is the same shape wherever it lives. A DM's own
module, say a book they own, is that folder on their machine, imported
from the app; it never enters this repository.

**Licensing.** Only content Tablewright may redistribute goes here:
the SRD under CC-BY-4.0, and homebrew that is CC-BY-4.0 or licensed
to Tablewright. Each module's `module.json` carries the notice its
licence requires, and the app shows it in its credits.

`systems/5e/content/2024/srd` is generated by `bun run import:srd`
from Open5e's SRD 5.2 document. It is committed, so an upstream change
shows up as a diff when the import is re-run. Do not edit those files
by hand; fix the importer.
